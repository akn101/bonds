# Community Projects

Community-maintained projects extend Bonds to other platforms and workflows. These projects are developed independently and are not officially supported by the Bonds maintainers. Please report project-specific questions and issues to the linked repository.

## Home Assistant Add-on

The [Bonds Home Assistant add-on](https://github.com/mrwogu/hassio-addons/tree/main/bonds), maintained by [@mrwogu](https://github.com/mrwogu), packages Bonds for Home Assistant OS. It uses SQLite by default, supports an external PostgreSQL database, and integrates persistent data and backups with Home Assistant's add-on environment.

[View installation and configuration instructions](https://github.com/mrwogu/hassio-addons/tree/main/bonds)
