# 社区项目

社区维护的项目可以将 Bonds 扩展到其他平台和使用场景。这些项目由社区独立开发，不属于 Bonds 维护者的官方支持范围。有关具体项目的问题和反馈，请前往对应仓库提交。

## Home Assistant Add-on

由 [@mrwogu](https://github.com/mrwogu) 维护的 [Bonds Home Assistant add-on](https://github.com/mrwogu/hassio-addons/tree/main/bonds) 可在 Home Assistant OS 中运行 Bonds。它默认使用 SQLite，也支持外部 PostgreSQL 数据库，并将持久化数据和备份集成到 Home Assistant 的 add-on 环境中。

[查看安装与配置说明](https://github.com/mrwogu/hassio-addons/tree/main/bonds)
